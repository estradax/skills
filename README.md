# skills

Agent skills for working with Blender through Claude.

## Install

```bash
npx skills add <github-user>/<repo>
```

## Skills

| Skill | What it does |
| --- | --- |
| [`blender-step-build`](blender-step-build/SKILL.md) | Build or animate a Blender scene live, step by step, paced for screen-recorded demos, using the omnix MCP (`blender.run_python`). |

Requires Blender with the omnix add-on running and "Allow run_python" enabled in the add-on preferences.
